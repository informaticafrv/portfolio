# Portfolio Web

Sitio web de portfolio estático para desarrollador web, adaptado al currículum de Francisco Romero Velázquez.

## Estructura

- `index.html` - página principal
- `styles.css` - estilos responsivos y modernos
- `script.js` - manejo simple del formulario

## Personalización

1. Reemplaza el nombre, email, teléfono y enlaces en `index.html`.
2. Cambia los proyectos y la experiencia por tu información real.
3. Ajusta las tecnologías en la sección de habilidades.
4. Si quieres recibir mensajes, conecta `script.js` a un backend o servicio de correo.

## Cómo usar

Abre `index.html` en un navegador o despliega en cualquier servidor web.
